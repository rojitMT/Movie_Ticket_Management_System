# Movie Ticket Booking System

This project is a software development project for a Movie Ticket Booking System. The project demonstrates how software development can be planned, documented, and managed using Agile project management and version control tools.

## Project Overview

The Movie Ticket Booking System is designed to allow users to browse movies, view available showtimes, select seats, and book movie tickets. Administrators can manage movies, showtimes, bookings, and other system information.

This project focuses on the planning, requirements analysis, system design, testing, and project management of the proposed system rather than actual software implementation.

## Project Contents

- **Requirements** - Functional requirements, non-functional requirements, and stakeholder analysis.
- **Design** - UML diagrams including Use Case, Class, Sequence, and Activity Diagrams.
- **Project Management** - Product backlog and Gantt chart.
- **Testing** - Test case matrix covering different testing approaches.
- **Evidence** - Screenshots and evidence of Trello and GitHub activities.

## Tools Used

- Trello - Project planning and task management
- GitHub - Version control and document management
- Draw.io - UML diagram creation
- Microsoft Excel - Test cases and project data
- Gantt Chart Tool - Project scheduling

## Team

This project is completed collaboratively by two team members using Agile practices and GitHub for version control.

## Project Status

The project is currently in the planning, documentation, design, and testing stage. The system is proposed for academic purposes and is not implemented as a working application.
